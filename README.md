# 聊天存档 · 按楼层总结

独立的 SillyTavern / TauriTavern 前端扩展，不依赖小手机，不读小手机记录，不需要新后端。

## 用法

1. 打开酒馆的一段会话，从输入框旁的扩展菜单或扩展设置点击「聊天存档」。
2. 填起止楼层，或用「最近 N 楼」快捷填入。**#0 是第一楼，起止两端都包含**，与酒馆显示的编号一致。
3. 可先「查看选中原文」，再点「生成存档」。确认后只发 **一次请求**，使用酒馆当前 **聊天补全 / Chat Completion** 连接。API 地址、密钥、模型和输出上限仍由酒馆管理，本插件不保存密钥。
4. 审阅并编辑摘要后，「保存草稿到当前会话」。默认不启用，不会删改聊天原文。可以导出 Markdown 文本或本会话的 JSON 存档备份。
5. 在下方条目中手动「启用替代」，后续正常生成才会用这份摘要替代相应原楼层；停用或删除摘要即可恢复原文上下文。

生成时只发送所选楼层的可见文字及下面的总结提示词，不自动添加角色卡、世界书、未选楼层或其他角色的聊天。原文不跑正则、不展开 `{{宏}}`，不进行静默截断或自动分批。范围太大时请分成数段；模型/中转也可能拒绝、限制或截断过长请求，不能把一次返回视为已无损包含全部原文。

## 总结提示词

以下逐字保留用户指定的提示词（原格式）：

```text
请把下面这段聊天记录压缩成存档，用于下次对话代替原文。要求：
按时间顺序分段，标注日期。
用户的原话尽量保留，尤其是带情绪的句子、她对自己的判断、她做的决定，用引号标出。
助手的回复只保留核心结论和具体建议
单独列出"纠正记录"：用户纠正过助手的地方，原样记下。
单独列出"硬规矩"：用户明确说过不要做的事。
最后写"当前状态"：只写截至最后一楼的现状和未结的事，不写历史。
不要推测、不要补充原文没有的信息；不确定的地方标"未确认"。
不要美化或淡化用户的情绪，也不要替她下结论。
```

记录中的日期来自各楼的 `send_date`，由酒馆的时间解析器格式化；无法确定时标记「未确认」并保留原时间字段，不猜当前日期。

## 安装

在酒馆扩展的「按 URL 安装」中填写：

```text
https://github.com/ddebug/st-chat-archive
```

这是独立仓库，不需要卸载或替换小手机。安装后刷新酒馆。

无需 npm 安装或构建。将本插件的文件放入独立扩展目录，根下直接包含 `manifest.json`、`index.js`、`core.js`、`style.css`，随后刷新酒馆。

通常为 `data/<用户>/extensions/st-chat-archive/`；不同宿主版本路径可能不同。若从 URL 安装，需要可访问的 Git 仓库；私有仓库需要宿主能取得凭据，本插件不修改 git 认证。

## 替代的边界与保护

- 原消息不删除、不隐藏、不改内容；只修改宿主传入的临时 `coreChat` 数组。摘要是新的历史资料消息，不复制原消息的附件、工具调用、reasoning 或 swipe 对象。
- 每份摘要保存原范围和前缀的 SHA-256 指纹。编辑原文、删楼/插楼、切换 swipe 或重写源楼层后，不再使用旧摘要，保留原文并提示重新总结。失效记录保留供查阅，不自动覆盖。
- 多份启用存档不能重叠；编辑摘要再保存会将它停用，须重新审核启用。
- **当前最后一楼始终保留**，避免破坏 continue / regenerate / swipe。若归档包含最后一楼，等有新消息、它不再是最后一楼后再替代。
- 含附件或工具调用的范围只允许生成文字摘要并导出，不自动移除附件/工具消息。对已标记为「排除上下文」的范围不发请求，也不重新注入相应摘要。
- 如果宿主没有可验证的原楼层来源标记，或其他插件改变了消息结构，本轮不替代，不用日期/同名/相似文本猜楼层。旧版本 / TauriTavern 的实际兼容性需在对应宿主中确认；不能安全映射时保留原文。
- 摘要在正常生成的 interceptor 阶段替换、随后仍受酒馆的上下文预算及其他插件影响。酒馆 dry-run/token 预览可能未反映替代后的实际上下文。
- 摘要为模型生成，并非逐字无损；引用、纠正和硬规矩请人工核对。API 明确返回长度截断/内容过滤时，不允许直接保存为完整存档。

## 保存、隐私及撤销

存档仅保存到**当前会话** `chatMetadata.st_chat_archive_v1`，不是源码文件，也不写角色卡或全局设置。随酒馆聊天备份/导出保存。生成期间取消、切聊天或检测到其他正常生成会中止本插件请求；切换后的旧草稿仍可导出，但不能存到新会话。

宿主 `saveMetadata()` 实际会保存聊天和 metadata，且部分版本内部吞保存错误，无法提供可靠写盘回执。本插件只提示「已提交宿主保存」，不宣称读回核验成功；保存期间不要切会话或关闭页面，重要内容请额外导出。不同浏览器/设备并发编辑同一聊天没有服务器原子锁，不支持并发一致性保证。

不添加遥测；仅在点击并确认生成后通过酒馆的当前连接发送所选文字。导出的摘要和 JSON 备份含私人聊天，请勿提交到 GitHub。没有自动导入 JSON 或批量覆盖原聊天的功能。插件关闭后自动替代停止，原文一直存在。
